## [6.6.0] - 2026-08-23

### Added
- Integration tests for the `dbTable` and `sshCerts`/`x509Certs` export commands,
  including a fixture-based suite that runs against a real step-ca Badger database
  snapshot (skipped automatically when the snapshot is absent, e.g. in CI).
- Fuzz targets for the certificate and revocation JSON parsers.
- `AGENTS.md` with build instructions and contributor guidance.
- `SECURITY.md` vulnerability disclosure policy.
- Dependabot configuration for Go modules and GitHub Actions.

### Changed
- Refactored the output/emit system into a shared, data-driven column model
  (`output_sshcerts.go` split into `aux_output.go` + `aux_column.go`). No CLI flags
  or output formats changed; this is an internal reorganisation of the rendering path.
- Added a `.golangci.yml` linter configuration.

### Notes
- Coverage on the `cmd` package is now 87.3% (up from no committed test suite).
- This release contains no breaking changes to the CLI surface.
